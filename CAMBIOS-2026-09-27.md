# KickoffIVA — parche 2026-09-27 (Cloudflare Pages Functions + frontend)

Destino real de la app: Cloudflare Pages (`kickoffiva.cl`, `api.kickoffiva.cl`) + Neon Postgres.
El servicio de Railway (MySQL) es la app antigua y NO recibe tráfico del sitio.

## Archivos modificados
- `functions/api/empresa.ts` — GET sin empresa → **404 "Sin empresa"** (antes 401 → el frontend cerraba la sesión = "401 fantasma"). PUT sin empresa → 400. `tasaPpm` como número.
- `functions/api/empresas.ts` — POST: **409 "Ya tienes una empresa con ese RUT"** (RUT normalizado en SQL) + nombre sanitizado + captura de violación 23505.
- `functions/api/auth.ts` — registro: nombre obligatorio y sanitizado, correo normalizado, RUT de empresa validado/formateado.
- `src/lib/api.ts` — login/register no envían token ni convierten 401 en "sesión expirada"; `getEmpresa()` devuelve `null` con 404; limpia empresa activa de sesiones anteriores al iniciar sesión.
- `scripts/verify-api.mjs` — 4 checks nuevos (404 sin empresa, 400 sin nombre, 409 duplicado, sanitización).

## Archivos nuevos
- `functions/_lib/sanitize.logic.mjs` + `functions/_lib/sanitize.ts`
- `tests/sanitize.test.mjs` (12/12 tests pasan con `node --test tests/*.test.mjs`)
- `migrations/002_empresas_unicas.sql` — candado único en Neon (correr en SQL Editor; opcional, el backend ya bloquea duplicados).

## Deploy (desde kickoffiva-web/)
```powershell
npm install
npx tsc -p tsconfig.functions.json
npm run build
npx wrangler pages deploy
node scripts/verify-api.mjs https://api.kickoffiva.cl
```
